# UBL 2.1 XML Schemas (test fixtures)

Official OASIS UBL 2.1 (CS1) schemas, used only by the tests to validate the XML
generated by `ubl-engine` with `xmllint`.

- Source: `com.helger.ubl:ph-ubl21:10.2.1` on Maven Central (path
  `external/schemas/ubl21/` inside the jar), SHA-1 of the jar
  `fa21c93b747d4ec8ac954c646718641f2e0853a7` as published by Maven Central.
- Copyright (c) OASIS Open 2013. Distributed under the OASIS IPR Policy; see the
  header of each file.

Dependent schemas, from the same publisher on Maven Central (SHA-1 of each jar as
published): `com.helger.xsd:ph-xsds-ccts-cct-schemamodule:4.1.1`
(`5840affedf33573bf4b27116907ceb5de5cb0fae`), `ph-xsds-xmldsig:4.1.1`
(`80df5cc660c99408395b6a3791a2e39980ad528a`), `ph-xsds-xades132:4.1.1`
(`bc2ea49bc39ac84082924b7e70d97d36cc1b3279`) and `ph-xsds-xades141:4.1.1`
(`75dacd75bd992bcde4ae4da0cf9e8521b3e2db73`), stored under `common/` with the official
UBL 2.1 file names.

The only modification: ph-ubl resolves some `xsd:import` elements through a catalog, so
`schemaLocation` hints pointing to the local files were added to those imports
(`UBL-UnqualifiedDataTypes`, `UBL-SignatureAggregateComponents`, `UBL-XAdESv132`,
`UBL-XAdESv141`). No type or element definition was changed.

Only the five document schemas the service produces are kept under `maindoc/`.

These schemas validate the UBL structure only. DIAN-specific rules (Anexo Técnico,
`sts:DianExtensions`) are not covered: `ext:ExtensionContent` is skipped by UBL.
